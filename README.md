# Spikeball Ref

A web app for your iPhone that watches a roundnet (Spikeball) set through the camera. It flags rim hits, roll-ups and double bounces as they happen, and keeps the last 2.5 seconds for slow-motion replay.

Open the GitHub Pages link in Safari. To install it, tap Share, then Add to Home Screen.

- `tracker.js`: finds the ball and decides what each bounce was
- `demo.js`: a drawn practice scene for trying it without a camera
- `app.js`: camera, scoreboard, replay and setup screens
